# Contributing

Contributions should improve a demonstrated production decision, tool behavior, or failure mode without turning one project preference into a universal rule.

Before opening a pull request:

1. Keep skill descriptions narrow enough to route correctly.
2. Preserve source media, editable lineage, permission boundaries, and human-review gates.
3. Add or update a behavioral test for deterministic script changes.
4. Do not vendor copyrighted documentation or private production media.
5. Run `python3 -m unittest discover -s tests -v`.
6. Confirm no local paths, credentials, transcripts, client names, or source-media metadata were added.

When changing Adobe guidance, prefer current official Adobe documentation where available and label community or undocumented APIs accurately.
