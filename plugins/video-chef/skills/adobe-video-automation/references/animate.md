# Adobe Animate scripting

Source: https://github.com/docsforadobe/animate-scripting-guide

Use Animate automation only when it supports a concrete video or motion-graphics asset workflow. Consult the guide's application, document, timeline, and window objects for the exact installed version.

Work on a copy of the document. Resolve the active document, scene, timeline, layer, frame range, symbol/library item, and publish profile before mutation. Preserve registration points, symbol nesting, frame labels, easing, and stage dimensions unless the request changes them. After publishing, inspect the generated asset in the target video composition or edit; a successful Animate publish does not prove integration quality.
