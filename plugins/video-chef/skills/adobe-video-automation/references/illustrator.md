# Illustrator scripting for video assets

Source: https://github.com/docsforadobe/illustrator-scripting-guide

Use Illustrator scripting to create or prepare editable titles, diagrams, logos, lower-third elements, and other approved vector assets for a video. The guide covers script execution and the JavaScript object reference for documents, artboards, layers, page items, paths, text, placed items, swatches, export, and related collections.

Confirm artboard dimensions, coordinate system, units, document color space, font availability, linked or embedded assets, naming, and target export before mutation. Preserve editable source artwork and create derived exports separately. Verify transparency, bounds, text outlining policy, color conversion, and how the asset appears when imported into the target NLE or motion project.

Illustrator-generated artwork is a production asset, not footage or evidence. Do not use it to fabricate documentary source material.
