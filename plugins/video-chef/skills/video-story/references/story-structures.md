# Story structures

Choose a structure because it serves the audience promise, not because it is fashionable.

- **Problem → stakes → approach → proof → takeaway:** launch, product, and operational explainers.
- **Question → investigation → discovery → implication:** documentary and research-led work.
- **Before → turning point → after:** transformation and case study, only when evidence supports the change.
- **Claim → demonstration → boundary → next action:** demos and training.
- **Moment → context → meaning:** short social or testimonial pieces.
- **Chronological with purposeful compression:** events and process work where sequence matters.

For each beat, state the audience question it answers, the source evidence available, the intended duration, and what becomes unnecessary if the beat is removed. Avoid redundant restatement disguised as a new beat.

The hook should create useful orientation or tension without overstating the evidence. The ending should resolve the promise or state the honest remaining uncertainty.
