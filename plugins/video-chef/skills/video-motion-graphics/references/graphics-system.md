# Motion-graphics system

Define roles before components:

- identity: title, name, role, chapter;
- emphasis: one phrase or idea worth holding;
- explanation: diagram, label, data, or product callout;
- navigation: step, progress, location, or transition;
- utility: captions, source labels, legal copy, or disclosure.

Set type hierarchy, safe areas, grid, spacing, color roles, stroke/shape language, entrance/exit grammar, hold behavior, and maximum simultaneous information. Design for the actual aspect ratio and viewing size. Test long names, localization, and caption coexistence.

Use motion to establish causality, hierarchy, continuity, or emphasis. Prefer a few repeated behaviors to many unrelated effects. Preserve reduced-motion alternatives when the destination supports or requires them.
